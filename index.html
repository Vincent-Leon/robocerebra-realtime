Can robot agents think fast enough?

A benchmark for language-model agents controlling a simulated robot on long-horizon household tasks, where the world keeps moving while the model thinks. Every decision costs time, objects get displaced, and the scene changes under the agent's feet.

Tasks

60 long-horizon tasks in six categories, built on the RoboCerebra scenes (LIBERO / robosuite, MuJoCo, 20 Hz control). Each task is scored by the fraction of its ordered subgoals completed within 300 s; the reference is a scripted executor replaying the demonstration plan (no language model).

How it works

The simulator runs in real time. The agent reads timestamped snapshots, issues skill calls to a scripted executor, and can cancel them at any control step. Nothing waits for the model.

Environment

  • MuJoCo physics at 20 Hz; the agent sees object states and a 3rd-person camera image.
  • Skills: pick, place, place-on, pour, open / close drawer, turn on; each runs for seconds and can be interrupted.
  • Dynamics from RoboCerebra: random disturbances, observation mismatch, hidden objects in drawers.

Agent frameworks

    Clocks and metrics

    • Wall (default): the world advances during inference by the measured latency; results reflect decisions and serving speed. Hardware is reported per row.
    • Token: the world pauses during the call, then advances by a fixed cost: . Independent of hardware; rewards short outputs and cache reuse.
    • Paused: inference costs no environment time — an upper bound on decision quality.
    • Score: fraction of subgoals completed (± SD over 3 seeds). Success: whole task completed. pass^3: task completed in all 3 seeds.
